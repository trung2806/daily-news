### CVE-2026-116692
**MLflow: Remote code execution on unauthenticated MLflow servers via third-party scorer deserialization importing caller-placed artifact modules**

mlflow mlflow · CVSS 9.8 (v3.1) · EPSS 0.007 (top 46.4%) · Khai thác: VulnCheck KEV, SSVC: poc · Lý do: CVSS 9.8, tấn công qua mạng

#### Tóm tắt
Lỗ hổng nằm ở cơ chế deserialization scorer bên thứ ba trong mlflow/genai/scorers/base.py. Hệ thống chấp nhận các module con của THIRD_PARTY_SCORER_ALLOWED_MODULES thay vì yêu cầu khớp chính xác, ảnh hưởng MLflow từ 3.12.0rc0 đến trước 3.17.0. VulnCheck KEV đã ghi nhận lỗ hổng, còn CISA KEV chưa liệt kê.

#### Cách tấn công
Kẻ tấn công dùng các endpoint artifact của MLflow để đặt một module Python vào package được phép nằm trong thư mục ghi được. Sau đó gửi tên module và class qua endpoint scorer invoke để server import và khởi tạo class trước khi xử lý trace.

**Điều kiện khai thác:** Truy cập mạng tới MLflow server; nếu authentication bị tắt thì không cần thông tin xác thực; nếu bật basic-auth thì cần tài khoản có quyền tạo experiment, run và upload artifact; package scorer được phép phải có quyền ghi đối với tiến trình server.

**Ảnh hưởng:** Thực thi mã từ xa (RCE) trên server MLflow, CVSS 9.8 (C:H/I:H/A:H). Kẻ tấn công có thể kiểm soát toàn bộ máy chủ và dữ liệu ML được lưu trữ.

#### Khắc phục
- Nâng cấp MLflow lên phiên bản 3.17.0 (bản đã vá theo GHSA-26p8-2jq9-3vq9).

#### Giảm thiểu tạm thời
- Khuyến nghị chung: hạn chế truy cập mạng tới MLflow server, không mở trực tiếp ra Internet.
- Khuyến nghị chung: không chạy server ở chế độ tắt xác thực; bật basic-auth và giới hạn quyền tạo experiment/upload artifact.
- Khuyến nghị chung: đặt thư mục package scorer ở chế độ chỉ đọc đối với tiến trình server.
- Khuyến nghị chung: giám sát log upload artifact và request tới endpoint scorer; kiểm tra các file module lạ trong thư mục package nếu nghi bị khai thác.

### CVE-2026-126537
**Ninja Forms - File Uploads <= 3.3.36 - Unauthenticated Arbitrary File Deletion via 'files[].data.file_path' Parameter via 'extra.saveProgress'**

#### Tóm tắt
Plugin Ninja Forms - File Uploads (SaturdayDrive) đến hết 3.3.36 có lỗi kiểm soát đường dẫn file khi xử lý upload nền. Đường dẫn do client gửi không được chuẩn hóa hay kiểm tra thư mục upload trong luồng công khai, nên có thể bị dùng để xóa file tùy ý.

#### Cách tấn công
Kẻ tấn công gửi form công khai có tham số tiến trình lưu (saveProgress) và bỏ qua upload_id để tránh bước nạp lại đường dẫn từ server. Đường dẫn file do attacker kiểm soát đi vào hàng đợi upload nền và bị dùng cho thao tác xóa file.

**Ảnh hưởng:** Xóa file tùy ý trên server, CVSS 9.1 (I:H/A:H). Theo mô tả, việc xóa wp-config.php đưa WordPress về màn hình cài đặt, dẫn tới chiếm quyền toàn bộ site; RCE có thể xảy ra. Mô tả cũng nêu khả năng đọc file qua tích hợp S3/Dropbox/Google Drive.

#### Khắc phục
- Chưa có thông tin bản vá trong dữ liệu nguồn, theo dõi advisory của hãng.

#### Giảm thiểu tạm thời

- Khuyến nghị chung: nếu buộc phải dùng, tắt form công khai có upload file hoặc yêu cầu đăng nhập trước khi upload.
- Khuyến nghị chung: sao lưu và kiểm tra tính toàn vẹn của wp-config.php; đặt quyền file ở mức hạn chế nhất có thể.
- Khuyến nghị chung: giám sát log request tới form có tham số lưu tiến trình và cảnh báo khi file cấu hình biến mất hoặc site hiện màn hình cài đặt.

**Traccar: Authentication bypass via path parameters exposes protected device media**

Kẻ tấn công biết hoặc đoán được device unique ID và tên file media, sau đó thêm dấu chấm phẩy tại ranh giới Servlet. Request vượt qua kiểm tra session và quyền thiết bị của MediaFilter và được Jetty phục vụ file.

**Ảnh hưởng:** Lộ file media của thiết bị (ảnh, âm thanh, video, file khác), CVSS 7.5 (C:H). Advisory không ghi nhận directory listing, path traversal, sửa đổi dữ liệu, chiếm tài khoản, DoS hay RCE.

#### Khắc phục
- Nâng cấp lên Traccar 6.15.0 (bản đã vá theo GHSA-w59q-j9pg-pw7x).

#### Giảm thiểu tạm thời

- Khuyến nghị chung: cấu hình reverse proxy từ chối hoặc chuẩn hóa dấu chấm phẩy trong path tới /api/media/.
- Khuyến nghị chung: giám sát log truy cập /api/media/ có ký tự bất thường trong đường dẫn; rà soát media nhạy cảm đã lưu.

### CVE-2026-118965
**Path traversal in host label synchronization allows code execution on the central site from a remote site**

Checkmk GmbH Checkmk · CVSS 9.4 (v4.0) · EPSS chưa có · Khai thác: chưa ghi nhận · Lý do: CVSS 9.4, tấn công qua mạng

#### Tóm tắt
Checkmk (<2.5.0p19, <2.4.0p40, nhánh 2.3.0 EOL) có path traversal trong đồng bộ host label, cho phép ghi file tùy ý trên central site (CWE-22). CVSS 4.0 là 9.4 (CRITICAL).

#### Cách tấn công
Kẻ kiểm soát một remote site trong hệ thống giám sát phân tán gửi dữ liệu host label chứa đường dẫn traversal để ghi file ra ngoài thư mục dự kiến trên central site.

**Điều kiện khai thác:** Kẻ tấn công phải kiểm soát được một remote site trong môi trường distributed monitoring; quyền PR:L theo vector.

**Ảnh hưởng:** Ghi file tùy ý và thực thi mã với quyền user của site trên central site; ảnh hưởng C/I/A ở mức cao.

#### Khắc phục
- Nâng cấp lên Checkmk 2.5.0p19 hoặc 2.4.0p40 (theo checkmk.com/werk/22120).
- Nhánh 2.3.0 (EOL): Chưa có thông tin bản vá trong dữ liệu nguồn, theo dõi advisory của hãng.

#### Giảm thiểu tạm thời
- Khuyến nghị chung: chỉ kết nối remote site đáng tin cậy và giới hạn quyền của remote site.
- Khuyến nghị chung: giám sát file mới hoặc bị sửa đổi ngoài thư mục dự kiến trên central site và log đồng bộ host label bất thường.

#### Phiên bản
- Checkmk GmbH Checkmk: affected: 2.5.0 → < 2.5.0p19; affected: 2.4.0 → < 2.4.0p40; affected: 2.3.0
