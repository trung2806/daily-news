### CVE-2026-114432
**Contact Form 7 6.2 - 6.2.3 - Unauthenticated Arbitrary File Upload via Invalid UTF-8 Filename**

Unknown Contact Form 7 · CVSS 9.8 (v3.1) · EPSS 0.002 (top 88.0%) · Khai thác: VulnCheck KEV · Lý do: CVSS 9.8, tấn công qua mạng

#### Tóm tắt
Contact Form 7 (WordPress plugin) trước 6.2.4 không kiểm tra loại hoặc phần mở rộng của file tải lên qua trường file trong form, và lỗi dọn file tạm khiến file vẫn nằm trên đĩa. Dữ liệu ghi nhận lỗi thuộc CWE-434, CVSS 3.1 9.8 (Critical). Không có trong CISA KEV; có trong VulnCheck KEV nhưng không liệt kê exploit; EPSS 0.00215.

#### Cách tấn công
Kẻ tấn công không cần đăng nhập có thể tải lên một file tùy ý qua form có trường file. File không bị xóa khi dọn tạm nên tồn tại trên server. Nếu cấu hình web cho phép liệt kê thư mục và xử lý .phar bằng PHP, file có thể được tìm và thực thi.

**Điều kiện khai thác:** - Truy cập mạng tới site có form Contact Form 7 với trường file upload; không cần xác thực, không cần tương tác người dùng.
- RCE chỉ xảy ra với cấu hình Apache mặc định trên Debian/Ubuntu (liệt kê thư mục, ánh xạ .phar sang handler PHP).
- Với nginx hoặc Apache bật .htaccess override, phạm vi giới hạn ở việc ghi file vào thư mục uploads.

**Ảnh hưởng:** - Trên cấu hình Apache mặc định Debian/Ubuntu: Remote Code Execution trên server.
- Trên cấu hình khác: ghi file tùy ý vào thư mục uploads, có thể phục vụ nội dung HTML/SVG hoạt động từ chính domain của site (rủi ro XSS/phishing).

#### Khắc phục
- Nâng cấp Contact Form 7 lên 6.2.4 trở lên (dữ liệu xác định các bản từ 6.2 đến dưới 6.2.4 bị ảnh hưởng).

#### Giảm thiểu tạm thời
- Khuyến nghị chung: cấm thực thi script (PHP, .phar) trong thư mục uploads ở cấp web server.
- Khuyến nghị chung: tắt liệt kê thư mục (Options -Indexes) và chặn phục vụ file có phần mở rộng nguy hiểm trong uploads.
- Khuyến nghị chung: rà soát thư mục uploads tìm file lạ (.php, .phar, .html, .svg) và log truy cập tới chúng; nếu nghi bị khai thác, điều tra dấu hiệu xâm nhập trước khi khôi phục.

### CVE-2024-24809

traccar traccar · CVSS 8.5 (v3.1) · EPSS 0.544 (top 1.0%) · Khai thác: VulnCheck KEV, nuclei template · Lý do: CVSS 8.5, đã có exploit công khai

#### Tóm tắt
Traccar (hệ thống GPS tracking mã nguồn mở) trước 6.0 có path traversal kết hợp unrestricted upload file nguy hiểm, thuộc CWE-27 và CWE-434. Đăng ký tài khoản mở mặc định nên người dùng thường có thể đạt quyền để khai thác. CVSS 3.1 8.5 (High); EPSS 0.54413 (cao); VulnCheck KEV có ghi nhận nhóm 'infoleak'; không có trong CISA KEV.

Người dùng đã đăng ký tài khoản thường có thể tải file có tiền tố 'device.' vào thư mục tùy ý nhờ lỗi path traversal. Việc ghi file ngoài vùng dự kiến cho phép đặt nội dung độc hại trên server. Dữ liệu nêu khả năng dùng cho phishing, XSS và có thể thực thi lệnh trên server.

**Điều kiện khai thác:** - Truy cập mạng tới giao diện Traccar.

**Ảnh hưởng:** - Ghi file tùy ý vào thư mục hệ thống, dẫn tới phishing hoặc XSS qua nội dung được phục vụ.
- Có thể thực thi lệnh trên server (theo dữ liệu, mức 'potentially'); CVSS ghi nhận ảnh hưởng toàn vẹn cao và khả dụng thấp (I:H, A:L).

#### Khắc phục
- Nâng cấp Traccar lên 6.0 trở lên; dữ liệu xác nhận bản 6.0 chứa bản vá (commit b099b298f90074c825ba68ce73532933c7b9d901).

#### Giảm thiểu tạm thời
- Khuyến nghị chung: tắt đăng ký tài khoản mở và hạn chế truy cập giao diện Traccar trong mạng nội bộ hoặc qua VPN.
- Khuyến nghị chung: rà soát file có tiền tố 'device.' ở các thư mục ngoài vùng dự kiến và các tài khoản mới tạo gần đây.
- Khuyến nghị chung: giám sát log upload và hoạt động của tài khoản mới để phát hiện dấu hiệu khai thác.

- Khuyến nghị chung: quản trị viên không nhấp liên kết lạ khi đang đăng nhập WordPress; triển khai CSP và WAF để chặn tham số phản chiếu bất thường.
- Khuyến nghị chung: giám sát log có tham số error_description chứa ký tự script và kiểm tra danh sách tài khoản administrator mới tạo.
