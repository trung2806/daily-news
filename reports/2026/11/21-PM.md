**Ảnh hưởng:** - CVSS 3.1 điểm 9.8 (CRITICAL), ảnh hưởng đồng thời tính bảo mật, toàn vẹn và sẵn sàng (C:H/I:H/A:H).

### CVE-2026-120539
**Restrictions for BuddyPress <= 1.5.4 - Unauthenticated Remote Code Execution via Request URI String Interpolation in eval()**

seventhqueen Restrictions for BuddyPress · CVSS 9.8 (v3.1) · EPSS 0.022 (top 17.4%) · Khai thác: chưa ghi nhận · Lý do: CVSS 9.8, tấn công qua mạng

#### Tóm tắt
Lỗ hổng Remote Code Execution (CWE-95) trong plugin Restrictions for BuddyPress (bp-restrict) của seventhqueen trên WordPress, các phiên bản đến 1.5.4. URI của request được chèn vào biểu thức PHP trong chuỗi có dấu ngoặc kép rồi chạy bằng eval().

#### Cách tấn công
- Kẻ tấn công gửi một request GET có đường dẫn URL được thiết kế để cú pháp nội suy chuỗi của PHP được đánh giá.
- Vì PHP nội suy chuỗi trước khi eval() chạy, mã do kẻ tấn công cài vào được thực thi mà không cần thoát khỏi chuỗi; cơ chế escape của WordPress không ngăn được.

**Điều kiện khai thác:** - Không cần xác thực, không cần tương tác người dùng; chỉ cần một request GET tới site.
- Plugin bị ảnh hưởng ở phiên bản từ 1.5.4 trở xuống; các điều kiện lỗi bật sẵn mặc định và được kiểm tra trước bước kiểm tra đăng nhập.
- Site phải đang kích hoạt BuddyPress và Paid Memberships Pro cùng với plugin này.

**Ảnh hưởng:** - CVSS 3.1 điểm 9.8 (CRITICAL), ảnh hưởng C:H/I:H/A:H.
- Kẻ tấn công không xác thực có thể thực thi mã tùy ý trên máy chủ WordPress.
- Trạng thái trong dữ liệu: không có trong CISA KEV hoặc VulnCheck KEV; không ghi nhận public exploit template; EPSS 0.02157.

#### Khắc phục
- Nâng cấp plugin Restrictions for BuddyPress lên phiên bản 1.5.5 (theo tham chiếu release 1.5.5 trong dữ liệu nguồn).

#### Giảm thiểu tạm thời
- Khuyến nghị chung: nếu chưa nâng cấp được, tạm gỡ hoặc vô hiệu hóa plugin bp-restrict.
- Khuyến nghị chung: cấu hình WAF chặn các request có ký tự và cú pháp nội suy PHP bất thường trong đường dẫn URL.
- Khuyến nghị chung: rà soát access log web để tìm request GET có đường dẫn bất thường tới site; kiểm tra file PHP lạ, file mới được tạo trong thư mục WordPress và tiến trình đáng ngờ trên máy chủ.

#### Phiên bản
- seventhqueen Restrictions for BuddyPress: affected: <= 1.5.4
