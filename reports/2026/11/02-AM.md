### CVE-2026-120338
**Prefab UI Pyodide sandbox escape to host RCE**

PrefectHQ prefab-ui · CVSS 10.0 (v3.1) · EPSS chưa có · Khai thác: chưa ghi nhận · Lý do: CVSS 10.0, tấn công qua mạng

#### Tóm tắt
Lỗi sandbox escape trong Generative UI của prefab-ui (PrefectHQ): code Python do người dùng cung cấp chạy trong Pyodide bên trong tiến trình Deno, nhưng Deno API được để lộ qua đối tượng JavaScript global và Deno được khởi động với quyền đọc, ghi, mạng không giới hạn. Ảnh hưởng từ 0.14.0 đến trước 0.21.0. CVSS 3.1 10.0 (CRITICAL, nguồn JFROG).

#### Cách tấn công
Kẻ tấn công cung cấp code Python được chế tạo để gọi trực tiếp Deno API thông qua module js, từ đó đọc và ghi file với quyền của user OS chạy server. Kẻ tấn công có thể duy trì việc thực thi code bằng cách ghi file .pth vào site-packages của virtualenv server. Đường tấn công thường gặp là tool generate_prefab_ui của FastMCP GenerativeUI, chuyển tham số code vào sandbox.

**Điều kiện khai thác:** Tính năng Generative UI phải được bật (opt-in) và host đã cài Deno. Trên FastMCP server không cấu hình xác thực, bất kỳ client nào tới được server đều gọi được tool; khi có xác thực, bất kỳ client nào được phép gọi tool cũng khai thác được. Đã xác nhận trên prefab-ui 0.20.2.

**Ảnh hưởng:** Kẻ tấn công đọc, ghi file trên server và duy trì thực thi code bền vững qua file .pth. Đây là host RCE thông qua sandbox escape, với thay đổi phạm vi (S:C) và ảnh hưởng High đối với C/I/A.

#### Khắc phục
- Nâng cấp prefab-ui lên 0.21.0 trở lên. Theo dữ liệu, bản vá nằm trong commit 030f074 (pull request 538).

### CVE-2026-62048
**WordPress BookIt plugin <= 2.6.0.6 - SQL Injection vulnerability**

Liquid Web / StellarWP BookIt · CVSS 9.3 (v3.1) · EPSS chưa có · Khai thác: chưa ghi nhận · Lý do: CVSS 9.3, tấn công qua mạng

#### Tóm tắt
Lỗ hổng SQL Injection (CWE-89) trong plugin WordPress BookIt của Liquid Web / StellarWP, ảnh hưởng các phiên bản từ n/a đến 2.6.0.6. Dữ liệu đầu vào không được vô hiệu hóa ký tự đặc biệt trước khi đưa vào câu lệnh SQL.

#### Cách tấn công
- Kẻ tấn công gửi dữ liệu được chế tác tới endpoint của plugin có chứa ký tự SQL.
- Câu truy vấn gửi tới cơ sở dữ liệu bị thay đổi theo ý kẻ tấn công.

**Điều kiện khai thác:** - Khai thác từ xa qua mạng (AV:N, AC:L).
- Không cần tài khoản (PR:N) và không cần tương tác người dùng (UI:N).
- Không có trong CISA KEV; cisa_ssvc_exploitation ghi none; EPSS chưa có.

**Ảnh hưởng:** - Đọc được dữ liệu trong cơ sở dữ liệu với mức ảnh hưởng cao tới tính bảo mật (C:H), ảnh hưởng thấp tới sẵn sàng (A:L), phạm vi thay đổi (S:C).
- CVSS 3.1 điểm 9.3 CRITICAL (nguồn Patchstack).

#### Khắc phục
- Chưa có thông tin bản vá trong dữ liệu nguồn, theo dõi advisory của hãng.

#### Giảm thiểu tạm thời
- Khuyến nghị chung: gỡ hoặc vô hiệu hóa plugin BookIt nếu không cần thiết.
- Khuyến nghị chung: triển khai WAF để lọc tham số có dấu hiệu SQL injection tới endpoint của plugin.
- Khuyến nghị chung: giới hạn quyền database user của WordPress, giám sát log truy vấn bất thường; nếu nghi bị khai thác, kiểm tra dữ liệu và tài khoản quản trị.

#### Phiên bản
